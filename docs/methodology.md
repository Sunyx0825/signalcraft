# 信号与组合研究方法

## 输入与样本

基础模型为官方MASTER的CSI300开源数据seed0权重。模型输入包含8日窗口、158个股票特征及63个市场特征。训练权重冻结；本项目不重新拟合基础网络。

测试信号期为2020-07-01至2022-12-30，共611个交易日、183,300条股票日观测，每日300只股票。集合按历史成分变化，共涉及412只股票。价格来自2024-12-07发布的Qlib数据快照。导出价格面板时逐日核对历史成分，遗漏与额外成员均为零。

未来收益标签仅用于预测评价，不参与选股或组合收益计算。305条缺失标签观测仍保留在模型推断和选股输入中。

## 四组实验

| 名称 | 信号 | 持仓规则 |
|---|---|---|
| baseline | 原始预测分数 | 前30只 |
| smooth | 横截面百分位的指数平滑 | 前30只 |
| buffer | 原始预测分数 | 保留仍在前45的已有持仓，再补足30只 |
| smooth_buffer | 平滑后的百分位 | 同上 |

平滑系数为0.5。当天不在股票集合中的标的不会保留平滑状态，重新进入时以当日百分位初始化。相同分数使用稳定的股票代码顺序处理并列。所有参数固定，报告全部方案与三档费用。

## 交易与资金账本

1. `t`日收盘信息生成信号，`t+1`日收盘成交。新持仓从成交后开始承担价格变化。
2. 每日先按复权收盘价更新旧持仓价值，再计算买卖与费用。
3. 可成交条件为有效正收盘价、正成交量，以及绝对涨跌幅小于9.5%。这是一致应用于所有标的的简化代理条件。
4. 不可交易的已有持仓保留价值并占用名额。剩余目标按费用后的可投资资本等权配置；可选标的不足时保留现金。
5. 二分求解费用后的投资资本，确保`股票市值＋现金＝交易前净值－费用`。费用按买卖金额分别计算。
6. 最后一天先计入旧持仓价格变化，再清算可交易持仓并计费。测试期末全部持仓已清算。

缺价期间按上一有效价格估值。如果持有标的超过数据中的最后有效报价日，程序停止并要求明确退市处理，避免将持仓从账本中直接移除。

## 指标

- 年化净收益：`期末净值^(252 / 回测日期数) - 1`，含首日建仓和末日清仓费用。
- 日均单边换手：每日`(买入金额＋卖出金额) / (2×交易前净值)`的均值。
- Sharpe：日收益均值除以样本标准差，再乘`sqrt(252)`，无风险利率设为零。
- 最大回撤：净值相对历史峰值的最大跌幅，初始净值1纳入峰值序列。

回测共有610个日期，2020-07-02至2022-12-30。

## 解释范围

平滑加缓冲的优势出现在所测试的非零费用情景中；零费用收益及RankIC均未优于原始信号。持仓缓冲单组件在基准费用下的净收益高于组合方案。结论聚焦于减少不必要交易，未声称网络预测精度或普遍可交易收益提高。

统一9.5%阈值不等同于真实逐日涨跌停判断。分数股、收盘成交、无冲击成本和零现金利息均为研究假设。未根据结果选择最优参数；单一模型权重和一个测试区间的结果不外推为其他市场的稳定表现。
